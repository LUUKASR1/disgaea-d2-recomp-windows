# Idioma do launcher / Launcher language

Na versão de desenvolvimento **0.1.54-language-preview**, selecione **Português (Brasil)** ou **English** em **Idioma / Language**, na barra lateral. A troca é imediata quando o launcher está ocioso. Durante a preparação ou execução do jogo, o seletor fica desabilitado.

A escolha é salva em `launcher-language.json`, na pasta local do aplicativo, separada de `launcher-settings.json`. Sem preferência válida, o padrão continua sendo português. Trocar o idioma não muda as opções gráficas, os arquivos do jogo, os saves ou o idioma do próprio Disgaea D2.

A interface, os títulos e filtros dos diálogos, as mensagens comuns de preparação/execução e os controles de diagnóstico têm tradução. Logs técnicos, mensagens nativas do Windows e erros desconhecidos de ferramentas mantêm o texto original, incluindo códigos e caminhos. A versão pública 0.2.0 não é substituída por esta build de desenvolvimento.

## English

In development version **0.1.54-language-preview**, select **Português (Brasil)** or **English** under **Idioma / Language** in the sidebar. The interface changes immediately while the launcher is idle. The selector is disabled during setup and gameplay.

The choice is saved in `launcher-language.json` in the local application folder, separately from graphics settings. Portuguese remains the default when no valid preference exists. Changing the launcher language does not change graphics settings, game files, saves or the game's language.

The interface, dialog titles and file filters, common setup/gameplay messages and diagnostic controls are translated. Technical logs, native Windows messages and unknown tool errors retain their original wording, codes and paths. This development build does not replace public release 0.2.0.
